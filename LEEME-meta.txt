KyoWidgets · 💰 Meta de donaciones — cómo activarla (una sola vez)
==================================================================

Qué hace: lee los tips de StreamElements (tu página de donaciones sigue siendo la misma),
guarda el total en Supabase y lo muestra en OBS. Si recargas OBS o el widget, el total NO se pierde.

1) Supabase → SQL Editor → New query: pega supabase/sql/08_meta.sql → Run.

2) Supabase → Edge Functions → Deploy a new function → nombre: meta
   Pega supabase/functions/meta/index.ts → Deploy.
   En sus ajustes, "Verify JWT" DESACTIVADO (el widget de OBS no manda cabeceras).

3) Token de StreamElements (para leer los tips):
   StreamElements → tu cuenta → Channels → "Show secrets" → copia el "JWT Token".
   Supabase → Edge Functions → Secrets → nuevo secreto: STREAMELEMENTS_JWT = (el token)
   OJO: es una clave privada. No la pegues en el repo ni la enseñes en directo.
   Si StreamElements la renueva, el Estudio avisará de que "rechazó el token":
   copia la nueva y actualiza el secreto.
   Sin token la meta funciona igual, pero solo a mano.

4) GitHub Desktop → Commit + Push. Espera 1–2 min y abre el Estudio con Ctrl+F5.

5) Estudio → 🧰 Widgets → 💰 Meta de donaciones:
   - Pon el título, la meta y la moneda (solo se cuentan tips de esa moneda). Guardar.
   - Si ya llevabas dinero en la meta de StreamElements: "✏ Poner total" con esa cifra.
   - 🔄 Consultar StreamElements para comprobar la conexión (arriba sale verde/rojo).
   - 📋 OBS → Fuente de navegador (640 × 200 en Pegatina normal).
   - ↺ Meta nueva pide doble clic: empieza a contar desde ese momento.

Notas: los tips nuevos aparecen en unos 10–25 segundos. Cada tip se guarda una sola vez
(por su id), nunca se cuenta doble. Los ajustes a mano (+/−, poner total) llegan al momento.
